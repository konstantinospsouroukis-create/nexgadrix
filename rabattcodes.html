So löst du einen Rabattcode ein

  1. Code oben kopieren.
  2. Über den Button zum offiziellen Shop wechseln und Produkt in den Warenkorb legen.
  3. Im Warenkorb oder an der Kasse das Feld „Rabattcode“ bzw. „Gutschein“ suchen und den Code einfügen.
  4. Prüfen, ob der Rabatt im Gesamtpreis abgezogen wurde, erst dann bestellen.
