# NEXGADRIX

German-language independent technology discovery website.

## Deployment

The website is a static `index.html` and can be served as static assets on Cloudflare Workers or Cloudflare Pages. Connect this repository to Cloudflare for automatic builds/deployments. For a Workers static assets build, use `wrangler.jsonc` in this repository.

## Editorial / legal status

This is an early preview. No affiliate links, checkout, or customer data collection are included. Before a commercial launch in Germany, add and verify legally compliant Impressum and Datenschutzerklärung with the site owner's real details and review the hosting data processing. Do not invent affiliate approvals or claim product tests were conducted.
