# NEXGADRIX

German-language independent technology discovery website.

## Deployment

The website is a static `index.html` and can be served as static assets on Cloudflare Workers or Cloudflare Pages. Connect this repository to Cloudflare for automatic builds/deployments. For a Workers static assets build, use `wrangler.jsonc` in this repository.

## Editorial / legal status

The site contains Amazon partner links on the product pages, marked as advertising (`rel="sponsored"`, "Anzeige"). There is no checkout and no customer data collection.

Legal pages: `impressum.html`, `datenschutz.html`, `kontakt.html`, `affiliate-hinweis.html`, linked from every footer. If hosting settings change (for example enabling analytics in Cloudflare), update `datenschutz.html` accordingly. Do not invent affiliate approvals or claim product tests were conducted.
